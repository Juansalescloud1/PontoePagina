# Ponto & Página

Loja demonstrativa estática feita com HTML, CSS e Javascript.

Este projeto é uma demonstração de interface: contas, pedidos e produtos usam
armazenamento do navegador e não há backend nem processamento real de pagamentos e não possui um banco de dados, a ideia é evoluir este trabalho nos próximos projetos.
Não use dados reais de clientes ou pagamentos.
